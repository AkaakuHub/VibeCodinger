# VibeCodinger privacy information

VibeCodinger does not send product usage analytics or connect to the upstream hosted relay. Resource diagnostics and trace files are stored by your installation. When you connect a client to your own server, the server can display its resource diagnostics to authenticated clients with access to diagnostics.

The agent providers you configure receive the requests you send to them. Which data they receive depends on which provider and features you use. Consult each provider's documentation for its data practices.
